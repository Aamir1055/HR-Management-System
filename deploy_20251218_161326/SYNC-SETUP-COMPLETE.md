## ⚠️ **Important Notes**

### **Files That Are NEVER Synced:**
- `.env` files (contain sensitive data)
- `node_modules/` (too large, installed via npm)
- `dist/` (generated by build)
- `uploads/` (user-uploaded files)
- `.log` files

### **After Backend Changes:**
Always restart the service:
```bash
pm2 restart backend
```

### **After Frontend Changes:**
Rebuild on server:
```bash
npm run build
```

### **Database Schema Changes:**
Run migrations:
```bash
cd backend
node migrate.js
```

## 🐛 **Troubleshooting**

### **Problem: SSH asks for password every time**
**Solution:**
```powershell
ssh-keygen -t rsa
ssh-copy-id deployer@65.20.84.140
```

### **Problem: Git push fails**
**Solution:**
```powershell
git remote -v  # Check remote
git remote add origin https://github.com/Aamir1055/HR-Management-System.git
```

### **Problem: Server pull fails**
**Solution:**
```bash
# On server
cd ~/HR-Management-System
git stash
git pull origin master
git stash pop
```

### **Problem: Services won't restart**
**Solution:**
```bash
# Check PM2 status
pm2 status

# Kill and restart
pm2 kill
cd ~/HR-Management-System/backend
pm2 start ecosystem.config.js
```
